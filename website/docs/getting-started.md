# Getting started

## 1. Install the app

[Download](/download) the latest APK on your Android phone (Android 9 or newer) and install it.

## 2. Install an extension for your router

RouterHub has no router code built in. Open the [extension list](/extensions/), find your router family and
download its APK, then install it like the app.

Open **Browse → Extensions** in RouterHub. The extension shows up there, marked **Official**.

::: tip Just looking around?
Install the **Demo (fake router)** extension. It pretends to be a router, so you can try every screen
without touching a real one. Any address and password work; the password `wrong` shows the
wrong-password flow.
:::

## 3. Add your router

1. Open the **Routers** tab and tap **Add router**.
2. Pick the firmware your extension provides.
3. Enter the router's address (often `192.168.0.1` or `192.168.1.1`) and the admin password, the one you
   use for its web page.

RouterHub signs in and shows the router's status: the internet connection, Wi-Fi bands and connected devices.
Tap **Settings** to change what the extension supports.

## Keeping up to date

- **The app**: **More → About → Check for updates**.
- **Extensions**: new versions appear in the [extension list](/extensions/); install the new APK over the old
  one.
