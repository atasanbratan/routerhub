# Extensions

Each extension teaches RouterHub one router family. Download the APK on your phone and install it, then
open **Browse → Extensions** in the app. Extensions from this list are signed with the official key, so the
app marks them **Official** and loads them right away.

Don't see your router? [Request it](https://github.com/atasanbratan/routerhub-extensions/issues/new/choose) or
[write an extension](https://github.com/atasanbratan/routerhub/blob/main/docs/writing-an-extension.md).
